# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

- Use GitHub's private vulnerability reporting: **Security → Report a vulnerability**
  on this repository.
- Security contact e-mail: `matti.mieskonen@gmail.com`.

Please include what you found, how to reproduce it, the affected version or commit,
and the impact you expect.

## Supported versions

Only the latest release (and the latest commit on `main`) receives security fixes.
